# 💼 Job Portal System

A streamlined web platform connecting job seekers with recruiters, enabling seamless job search, profile management, application tracking, and vacancy management.

---

## 🎯 Project Objectives

- 🔍 **Easy Job Search:** Search and filter job opportunities effortlessly.
- 👤 **Profile Management:** Create, update, and manage job seeker profiles.
- 📄 **Easy Applications:** Apply directly to suitable positions.
- 🏢 **Recruiter Tools:** Post and manage job vacancies efficiently.
- 📋 **Application Review:** Review and manage candidate applications in real time.
- 🔔 **Status Updates:** Keep applicants informed about application status.
- ⚡ **Streamlined Hiring:** Reduce time and manual effort in traditional recruitment.

---

## 🚀 Quick Start Guide

### Prerequisites
- Node.js & npm installed
- Visual Studio Code or Terminal (CMD/PowerShell)

### Setup & Run Instructions

#### 1. Frontend Setup
Open terminal and run:
```bash
cd frontend
npm install
npm run dev
```

#### 2. Backend Setup
Open a **new terminal tab/window** and run:
```bash
cd backend
npm install
npm run dev
```

#### 3. Access the Application
1. Open the `localhost` URL shown in the frontend terminal output (e.g., `http://localhost:5173`).
2. Register a new account using your **Email ID** and **Password**.
3. Log in to access the platform.
